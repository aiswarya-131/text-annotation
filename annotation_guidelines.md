Annotation Guidelines

1. Project Purpose

This project classifies short customer-service messages by sentiment, intent, and escalation requirement.

2. Sentiment Labels

- Positive: Expresses satisfaction, appreciation, or praise.
- Negative: Expresses dissatisfaction, frustration, or an explicitly negative opinion.
- Neutral: Requests information or states facts without a clear positive or negative emotional tone.
- Mixed: Expresses both positive and negative opinions in the same message.

3. Intent Labels

- Feedback: Shares an opinion or experience.
- Complaint: Reports dissatisfaction or a service/product problem.
- Product Inquiry: Asks about product details, price, or availability.
- Refund Request: Requests a refund or order cancellation.
- Technical Support: Reports a technical issue or requests help with a technical problem.
- General Inquiry: Asks a general question or provides an update that does not fit another defined intent.

Choose the primary intent based on the main purpose of the message.

4. Escalation Labels

- Yes: An unresolved problem requires support or corrective action.
- No: The message is routine feedback, a general question, or information that does not indicate a problem requiring intervention.

Negative sentiment alone does not automatically require escalation.

5. Annotation Rationale

Write one concise sentence explaining the label choices. Base the rationale on the message itself and avoid inventing details.

6. Consistency Rules

- Use only the defined label values.
- Apply the same definitions to similar messages.
- Review ambiguous examples before finalizing them.
- Correct spelling and formatting errors without changing the original message's meaning.
- Record any guideline changes and review affected annotations again.
